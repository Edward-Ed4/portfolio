Project Overview

The Hospital Management System (HMS) is a robust backend application built with Django 5.1.6, designed to digitize and streamline the complex operations of modern healthcare facilities. This system addresses the critical need for efficient patient data management, appointment scheduling, and medical record keeping.

At its core, HMS provides a comprehensive suite of modules that work together seamlessly. The system manages doctor profiles with their specializations and schedules, maintains detailed patient records with complete medical histories, and handles appointment bookings with intelligent conflict detection to prevent scheduling overlaps.

Built using Django REST Framework, the system exposes a well-documented RESTful API that can be consumed by various frontend applications—web dashboards, mobile apps, or third-party integrations. This architecture ensures flexibility and allows the hospital to adapt the user interface to their specific needs while keeping the robust backend intact.

Security and data integrity are paramount in healthcare. HMS implements role-based access control, ensuring that different staff members (doctors, nurses, receptionists, administrators) only access information relevant to their roles. All data transactions are validated and sanitized to prevent injection attacks and maintain HIPAA-compliant data handling practices.

The system is production-ready, configured with Gunicorn as the WSGI server and WhiteNoise for efficient static file serving. It supports both PostgreSQL and SQL Server databases, providing deployment flexibility based on the hospital's existing infrastructure.
